# ancs-bridge 0.1.0

The first production release provides a local, read-only bridge from an
iPhone’s native Apple Notification Center Service to Linux desktop
notifications.

Highlights:

- Encrypted HID-shaped ANCS accessory with no input-report emission.
- Added, Modified, and Removed notification forwarding.
- Passive recovery across iPhone disconnects, range loss, adapter/BlueZ
  disruption, suspend/resume, and reboot/login without generic Bluetooth
  connection attempts.
- Versioned JSON/JSONL machine API with atomic owner-only configuration and
  metadata-only runtime status and diagnostics.
- Transactional exact-device iPhone audio suppression plus a user-level
  Bluetooth output-only role policy that preserves AirPods playback and
  microphone support.
- Explicit setup confirmation, retry-safe teardown, bounded protocol/session
  resources, and a hardened unprivileged systemd user service.

The release was validated on the target Arch/BlueZ environment with physical
iPhone range-loss recovery, reboot/login startup, notification delivery,
privacy scans, WirePlumber audio invariants, and AirPods playback and
microphone checks.
